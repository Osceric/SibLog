# Siberian Logic

The Siberian Logic dashboard (working name): one page linking to each game's production site on Cloudflare, with a few sentences describing each.

- King of Demons: https://king-of-demons.siblog.workers.dev (repo: Osceric/King-of-Demons)

The page is `index.html`. GitHub Pages publishes it with GitHub Actions (`.github/workflows/pages.yml`) whenever `main` changes: https://osceric.github.io/SibLog/
